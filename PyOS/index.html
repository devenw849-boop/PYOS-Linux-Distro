what is inside

Built like a real distro foundation

▣

Bootable kernel

A custom x86 kernel with VGA text output, keyboard input, GRUB bootflow, and startup messages.

⛁

FAT16 storage

A simple FAT16 driver is used for reading and writing disk data in a classic OS-style layout.

◫

Package manager

PyOS includes a package manager model inspired by apt/dnf and a repo catalog with install metadata.

boot + testing

Run PyOS in QEMU

PyOS is designed to boot in a classic x86 VM environment. QEMU is the recommended first test target because it matches the old BIOS and IDE-style assumptions of this project. 

cd /home/ohio/PyOS
make run
